Which files to use
Use only the three files below, downloaded from the latest message in the chat with Claude. If a
file's size doesn't match, it's an older copy: delete it and download again.

 File          Size           What it's for

 seeds-        1,968,928      The full desktop project (app, main.js, preload.js, icons, build settings).

Before downloading, delete old copies from Downloads. Otherwise the browser saves the new
one as seeds (1).html or seeds-app (1).zip, and the steps below pick up the old file.
To check a file's size: on Windows, right-click it, choose Properties, and read "Size" (not "Size on
disk"). On a Mac, select it and press Cmd + I.
To check the app inside your build folder is the newest, run the check command in the update
steps. It searches for the words Smooth external display, which only the newest version has.


Windows: first-time setup
Do this once on a new PC, or to start completely fresh. It takes about 15 minutes, most of it
waiting.

   1. Install Node.js: go to nodejs.org, download the LTS installer (.msi), run it, and click Next
      through every screen with the default settings.
   2. Download seeds-app.zip from the chat into Downloads (delete any older copy first).
   3. Open Command Prompt: click Start, type cmd, click Command Prompt. The line must start
      with C:\Users\YourName> (if it starts with PS, that's PowerShell: close it and open
      Command Prompt instead).
   4. Check Node is installed. It should print a version such as v24.11.0:


 node -v


   5. Unpack the zip into a fresh build folder. Paste each line on its own and press Enter. The
      rmdir lines may say "cannot find the file": that's fine.
 cd "%USERPROFILE%\Downloads"
 rmdir /s /q seeds-src
 rmdir /s /q "%USERPROFILE%\seeds-build"
 mkdir seeds-src
 tar -xf seeds-app.zip -C seeds-src
 xcopy /E /I /Y seeds-src\seeds-app "%USERPROFILE%\seeds-build"
 cd "%USERPROFILE%\seeds-build"


   6. Install Electron and the builder (a few minutes; wait for "added … packages"):


 npm install


   7. Test without building. Close the window when you're done:

 npm start


   8. Build the installer and open its folder:


 npm run dist:win
 explorer dist


   9. Double-click the newest Seeds-Setup-….exe. If "Windows protected your PC" appears, click
      More info, then Run anyway.
 10. If the camera stays black: Start → Settings → Privacy & security → Camera → turn on "Let
     desktop apps access your camera". Do the same under Microphone.


Windows: updating
Use the first route when Claude sends only seeds.html, and the second when Claude says to use
the zip (main.js or preload.js changed). Both run in Command Prompt.
Only seeds.html changed. Delete the old seeds.html from Downloads, download the new
one, then:

 copy /Y "%USERPROFILE%\Downloads\seeds.html" "%USERPROFILE%\seeds-build\app\index.html"
 cd "%USERPROFILE%\seeds-build"


The zip changed. Delete the old seeds-app.zip and seeds-src from Downloads, download the
new zip, then:
 cd "%USERPROFILE%\Downloads"
 mkdir seeds-src
 tar -xf seeds-app.zip -C seeds-src
 copy /Y seeds-src\seeds-app\main.js "%USERPROFILE%\seeds-build\"
 copy /Y seeds-src\seeds-app\preload.js "%USERPROFILE%\seeds-build\"
 copy /Y seeds-src\seeds-app\app\index.html "%USERPROFILE%\seeds-build\app\"
 cd "%USERPROFILE%\seeds-build"


If seeds-src stays empty after tar, unpack it with this instead:
powershell -command "Expand-Archive -Force seeds-app.zip seeds-src"
Then, either way: check the app is the newest (this should print a line), test it, and build.

 findstr /c:"Smooth external display" app\index.html
 npm start
 npm version patch --no-git-tag-version
 npm run dist:win
 explorer dist


Run npm start on its own first and close ...Seeds before building. Then install the newest Seeds-
Setup-….exe. Your settings, patches and recordings folder are kept.


Mac: first-time setup
Do this once on a new Mac, or to start completely fresh. It takes about 15 minutes, most of it
waiting.

   1. Install Node.js: go to nodejs.org, download the LTS installer (.pkg), and click Continue →
      Agree → Install. Enter your Mac password if asked.
   2. Download seeds-app.zip from the chat into Downloads (move any older copy to the Trash
      first).
   3. Open Terminal: press Cmd + Space, type Terminal, press Return.
   4. Check Node is installed. It should print a version such as v24.11.0:


 node -v


   5. Unpack the zip into a fresh build folder. Paste each line and press Return:


 rm -rf ~/seeds-build ~/Downloads/seeds-src
 mkdir ~/seeds-build
 cd ~/Downloads
 unzip -o seeds-app.zip -d seeds-src
 cp -R seeds-src/seeds-app/. ~/seeds-build/
 cd ~/seeds-build


   6. Install Electron and the builder (a few minutes; wait for "added … packages"):
 npm install


   7. Test without building. Quit with Cmd + Q when done:


 npm start


   8. Build the installer and open its folder ("skipped code signing" is normal):


 npm run dist:mac
 open dist


   9. Quit Seeds, drag any old Seeds out of Applications, open the newest Seeds-…-arm64.dmg
      and drag Seeds into Applications.
 10. First launch: right-click Seeds in Applications → Open → Open. If macOS says it's damaged,
     run xattr -cr /Applications/Seeds.app in Terminal. If the Dock shows an old icon, run killall
     Dock; killall Finder.

For an older Intel Mac, use npm run dist:mac-intel instead of npm run dist:mac.

Web app on GitHub
Upload the new index.html to your seeds repository; devices pick it up the next time they open
the app online.

   1. Download index.html from the chat (delete older copies first so the name stays exact).
   2. On github.com, open the seeds repository, click Add file → Upload files, drag in index.html,
      and click Commit changes.
   3. Wait for the green check in the Actions tab.
   4. On a phone or tablet, close the app fully and reopen it. If it still shows the old version,
      open the site in Chrome and pull down to reload twice.

The web version is public: anyone with the link can open it, including the For Emmanuelle photo.
